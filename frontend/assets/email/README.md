# AZIEL email brand assets

These PNG files are optimized derivatives for email clients, which do not reliably render SVG images or webfont icons.

- `aziel-logo-primary.png` is derived from the canonical `frontend/assets/brand/aziel-logo-primary.svg` wordmark.
- `social/*.png` are derived from the Font Awesome Free 6.5.1 brand glyphs already used by AZIEL's public footer (`fa-facebook-f`, `fa-telegram`, `fa-youtube`, and `fa-discord`). Font Awesome Free icons are licensed under CC BY 4.0; source attribution and license information: https://fontawesome.com/license/free.

Delivered emails reference these assets through the stable public origin `https://azielplay.com/assets/email/`. The source SVGs are not duplicated here because the PNG files are the email-delivery artifacts.
