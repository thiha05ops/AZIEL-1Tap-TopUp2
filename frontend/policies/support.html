Support Policy

Last Updated : July 2026

Support Availability

AZIEL Support is available to help with orders, payments, account issues, and general questions. Response time depends on ticket volume and operating hours.

When Contacting Support

  • Order ID
  • Game Name
  • User ID
  • Server ID
  • Payment Method
  • Screenshot if available

Issues We Can Help With

  • Payment problems
  • Missing top-up
  • Wrong order status
  • Wallet issues
  • Account questions
  • General website support

Response Time

  • Normal : within 24 hours
  • Urgent payment issues : as soon as possible
  • Maintenance period : response may take longer

Community Rules

  • Be respectful to support staff.
  • No abusive language.
  • No spam or repeated tickets.
  • Provide accurate information.

Need assistance? Our support team is ready to help.
